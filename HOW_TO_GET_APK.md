# HOW TO GET YOUR APK

## A. Upload to GitHub
1. GitHub -> New repository
2. Name: sehat-ai-android
3. Create repository
4. Add file -> Upload files
5. Upload the CONTENTS of this folder (not the ZIP itself)
6. Commit changes

## B. Build
1. Open repository
2. Click Actions
3. Choose "Build Sehat AI APK"
4. Click "Run workflow"
5. Wait until it finishes successfully
6. Open the finished run
7. Download artifact: SehatAI-Android-APK
8. Extract it
9. Find app-debug.apk

## C. Install on phone
1. Send app-debug.apk to your phone/WhatsApp
2. Tap APK
3. If Android blocks it, allow "Install unknown apps" for WhatsApp/Files
4. Install
5. Open Sehat AI
